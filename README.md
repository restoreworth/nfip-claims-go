# nfip-claims-go

Per-state statistics of the building amount paid by the National Flood Insurance Program (NFIP) on claims with a
year of loss in 2020-2024, as a dependency-free Go package, computed from FEMA's OpenFEMA dataset
[NFIP Redacted Claims - v3](https://www.fema.gov/openfema-data-page/nfip-redacted-claims-v3).

**These are amounts paid by NFIP, not repair cost.** This package is not an official federal report.

```go
import nfipclaims "github.com/restoreworth/nfip-claims-go"

fl, ok := nfipclaims.Lookup("FL")             // StateStats, false for an unknown code
q, ok := nfipclaims.Position("FL", 25000)     // quartile 1-4; ok is false when status is "insufficient"
all := nfipclaims.States()                    // 51 records (50 states + DC), sorted by state
```

## Method

- Window: `yearOfLoss` 2020-2024; geography: 50 states + DC.
- Paid claims: `amountPaidOnBuildingClaim > 0`; amount: `amountPaidOnBuildingClaim`. `NClaims` counts all claim
  records of the state in the window, `NPaid` the paid ones.
- Quartiles: Hyndman-Fan type 7 (linear interpolation) on the paid amounts; values rounded to the cent.
- States with `NPaid` < 100: statistics left at zero, `Status` = `"insufficient"`.
- `TopEvent`: named flood event with the most paid claims in the state (`""` if none; share 0).
  `MedianExclTopEvent`: median of the paid claims not in `TopEvent` (claims without a flood event kept); set only
  when `HasMedianExclTopEvent` is true, i.e. when 100 claims or more remain.
- `EventDependent`: abs(MedianExclTopEvent - Median) / Median > 0.25.
- `Median2024USD`: each amount multiplied by CPI-U(2024) / CPI-U(year of loss), BLS series `CUUR0000SA0`. The
  dataset gives no payment date: the factor is applied to `yearOfLoss`, an approximation. The CPI is not a
  construction cost index: this field is a monetary adjustment, not today's cost of repair.
- `Position` places an amount against `Q1`, `Median` and `Q3`; a bound belongs to the lower quartile.

## Limitations

- These are amounts paid by NFIP, not repair cost. They are what NFIP paid the policyholder on the building, after
  deductible and capped by the coverage purchased; uninsured, undeclared or non-covered damage is not included.
- Not representative of all homes or all floods: only NFIP-insured properties with a claim that was paid.
- Amounts are nominal dollars of different years and of different disasters; one event can dominate a state (see
  `EventDependent`).
- No single-family series, no city, ZIP code or water-depth breakdown.
- No promise of cost, eligibility or claim amount for any individual.
- No endorsement by FEMA or DHS is stated or implied; no FEMA or DHS logo or seal is used.

## Generated data

`nfip_gen.go` is generated by `tools/gen_go.py` from `data/nfip_paid_claims_by_state.json` of the
`nfip-paid-claims-by-state` dataset, which is copied byte for byte to `testdata/` with the CSV next to it; the tests compare every field
of the 51 records with them. Do not edit `nfip_gen.go` by hand.
